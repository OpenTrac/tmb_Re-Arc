# AI Policy

This document contains information about this repository's policy on
agentic LLM and AI usage.

## Overview

Generally speaking, we **allow** LLMs to be used to contribute to this repository,
**as long as the submitted work meets our quality standards and requirements**.

## Restrictions

- **Do not ignore or bypass the existing AGENTS.md.**
  - This file dictates code quality standards and other requirements for our repo.
    Let your agent obey them.
    If `AGENTS.md` constrains your agent from peforming a specific task, it's almost
    certainly for a good reason.
- **Do not submit documentation generated by AI.**
  - LLMs are terrible at generating accurate, human-readable documentation of any kind.
    All documentation should be human-reviewed and formatted, even if it's based
    on LLM-assisted analysis.
- **Do not submit commit, issue, or PR descriptions generated by AI.**
  - If you're submitting code changes, we expect you to understand at a basic level
    what the code is doing and why design/variable naming decisions were made.
  - Using AI-generated descriptions indicates to us that you have no interest
    in understanding the code. Thus, we have no interest in reviewing it.
- **Do not submit slop or hacky matching code.**
  - The original source code was written by humans. Our goal is to reproduce that.
    **100% matching is a metric of correctness, not an end goal.**
  - TMB has debug symbols, so LLMs should have no trouble working out proper
    array and struct accesses and producing human-readable code.
    If you submit hacky code without a good justification, we'll know that
    you aren't reviewing your LLM's output.

Furthermore, **do not fork this repo with the express intent of bypassing these restrictions**
for any reason.

- Hostile forks will always produce a subpar product
  versus collaborating with the existing (knowledgable) community.
- You will fragment the Twisted Metal community.
  - The TM community in particular already has a lot of fragmentation issues;
    don't make it worse.
- We promise these restrictions will lead to a better final product that
  more people can enjoy in the long term.
